# Installation

Install packages via .NET CLI:

```bash
# Core - Query models, images, tags, creators
dotnet add package CivitaiSharp.Core --prerelease

# SDK - Image generation and job management
dotnet add package CivitaiSharp.Sdk --prerelease

# Tools - File downloads, hashing, HTML parsing
dotnet add package CivitaiSharp.Tools --prerelease
```
