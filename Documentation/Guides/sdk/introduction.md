# CivitaiSharp.Sdk

CivitaiSharp.Sdk is a client for the Civitai Generator API (orchestration). It handles authenticated tasks like image generation and job management.

## Installation

```bash
dotnet add package CivitaiSharp.Sdk --prerelease
```
